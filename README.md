# rounddance

An open-source Zigbee-compatible stack.

## What it is

A portable stack in Rust, with a `no_std` core, WASM-first, targeting Linux, ESP32, and browsers.

## Principles

- Built from published open standards only.
- Modular, composable layers.
- Coordinator, router, and end-device roles, including sleepy operation.
- Deterministic simulation.

## Status

Day-one scaffold — nothing implemented yet.
